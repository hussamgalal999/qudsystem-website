# QudSystem Official Unified Website (`qudsystem-website`)

> **التصنيف / Category:** `Enterprise SaaS & Business Systems`  
> **الحالة / Status:** Active • Unified Official Portal  
> **التقنيات / Tech Stack:** Next.js 14 • React 18 • TypeScript • Tailwind CSS • Framer Motion • PWA • SEO/LLM Ready

---

## 📋 الوصف الاحترافي | Overview

**العربية:**  
الموقع الرسمي الموحد لشركة **QudSystem**، يدمج أحدث الواجهات التفاعلية (`qudsystem-v12.5` Next.js 14) مع تحسينات محركات البحث والذكاء الاصطناعي (`Qudsystem V` — `llms.txt`, `sitemap.xml`, `robots.txt`, `offers.js`) والصفحات العربية والتفصيلية (`QudSystem.v09` / `v10`). كما يعمل كمركز موحد لإدارة **الخانة الإعلانية المركزية** لجميع منتجات الشركة.

**English:**  
The unified official corporate portal for **QudSystem**, consolidating all previous website versions (`v09`, `v10`, `Qudsystem V`, `v12.5`) into a single Next.js 14 platform with bilingual EN/AR support, AI/SEO metadata (`llms.txt`), product catalog, and centralized ecosystem ad-slot distribution.
